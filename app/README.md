# Application Folder (`/app`)

This directory houses the core backend source code for the Colour Labs Photographer CRM.

## Structure
- [core/](file:///d:/Projects/Lead%20CRM/app/core/README.md): Cross-cutting settings, database session setup, standard logging, and global exceptions.
- [api/](file:///d:/Projects/Lead%20CRM/app/api/README.md): Routing layer, version subfolders, endpoints, and dependency injection utilities.
- [main.py](file:///d:/Projects/Lead%20CRM/app/main.py): Entrypoint file that initializes the FastAPI application, mounts middlewares, hooks exception handlers, and hooks routers.
